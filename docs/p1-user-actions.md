## 模型私有配置的准备

将 `p1-model-config.example.json` 复制到访问受控的私有目录后填写。示例故意保留空模型/密钥、null 价格和零预算，不能通过就绪检查。密钥只填在本地私有副本，不发送到聊天、报告、截图或公开候选。价格依据由配置者核实，程序不代查或确认其正确性。

字段使用现有 `Settings` 契约。`agent_max_cost_microusd` 为每次调查上限，1 美元 = 1000000 microUSD；总费用/次数另行明确，当前程序没有跨调查的全局费用上限。配置文件只用于离线预检，不会自动修改应用环境或启用模型。后续获准真实验收时，应用仍通过同名大写环境变量读取配置；当前 Compose 强制 disabled、后端网络 internal，不应直接将模型参数塞入该演示部署来宣称联网已验证。

在完整开发工作区执行（不是候选包内命令）：

```powershell
.venv/Scripts/python -m scripts.p1_acceptance --output artifacts/p1-readiness-new.json
# 私有配置准备后，使用新的输出文件；路径替换为真实私有副本：
.venv/Scripts/python -m scripts.p1_acceptance --model-config C:/private/model.json --output artifacts/p1-readiness-configured-new.json
```

工具不调用模型、不打印端点/模型/密钥、不迁移数据库，只输出缺项代码、配置状态和每次预算。`configuration_ready` 只表示配置字段齐备，连接、价格、实际账单与真实模型验收仍未验证。成功生成报告也返回 exit 2，表示外部验收尚未完成；输入或输出无效为 exit 1，已有输出拒绝覆盖。该开发工具离线核对 eval 清单，所以没有装入运行候选。

人工执行后，将空白记录模板复制为新文件填写，附真实输入/输出摘要和本地证据路径。模板不是自动门禁，填写后仍须逐项复核，不会自动关闭 P1。签名字段保留实际人员确认，不能用程序输出替代。
