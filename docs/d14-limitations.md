# D14 限制

D14是固定D12应用/D13部署底座的离线依赖与演练增量，无应用字段/API/规则/Agent/数据库迁移变更。

- 离线包只包含Windows x64 CPython3.13兼容wheel；目标机须已有Python，不含完整系统镜像、Python安装器或Docker镜像。依赖字节锁与外部ZIP hash不是供应链签名。
- 主/备/回退是本机不同新目录；不是独立硬件、跨机容灾或非作者验收。恢复同版停机备份，不自动合并之后写入，也不原地降级数据库。
- 网络护栏覆盖本次Python进程socket审计和本次浏览器请求路由，不是操作系统防火墙、不证明整台机器没有外联。未修改用户网络、路由、代理或Docker配置。
- 连接中断与坏引用来自明确标记的本地故障协议桩；没有真实LLM调用，不将协议桩usage当作真实账单。
- 两轮自动计时/录屏不代替真人讲解、问答或现场物理断网彩排；真人记录表pending。
- 原始日志/对象、既有报告和密钥未修改。私有备份/运行库/初始化令牌不进入公开离线包或演示材料。
- 七项继承P1仍阻断完整P0：真实模型/费用、正式资料/标签、非作者恢复、回放/大规模全量检测、干净机器/Compose/非作者启动、现场彩排、知识库。项目最终分发许可仍需权利人确认。

应用版本继续0.1.0.dev12，底座历史测试与性能仍按原版本说明；D14只报告本轮实际测试、安装和演练结果。
