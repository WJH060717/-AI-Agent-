## 场景材料要求

每个独立场景至少包含：

1. **完整证据链**：网络连接/抓包、认证、进程或 socket、必要告警，能定位到原始记录。
2. **缺关键证据对照**：删除 socket、认证或时间绑定，预期路径出现断点/未知，而不是补造。
3. **正常业务对照**：监控、备份、授权扫描或正常登录，预期不产生目标行为或只产生正常解释。
4. 输入、来源、授权范围、SHA-256、采集时间、传感器实例、解析版本和失败记录写入 manifest。
5. 按完整活动链划分 dev/val/test；同一活动的派生片段、重放和改名重导不得跨集合。

## 指标

- 检测：逐规则/行为最大一对一匹配，未匹配预测为 FP、未匹配真值为 FN；不可观测步骤不计入可观测召回分母。
- 图/路径：预测边投影到真值 step 后去重；入口 Top-1/Top-3；断点是否正确。
- 补证：非种子新增事件数、有效判断变化、重复返回比例、未读页、停止原因。
- 成本/时延：每次/分组调查耗时、工具/模型次数、输入输出 token、预留费用、usage 估算、真实账单（未知为 null）。
- 报告：引用存在/授权率、有限谓词通过率、人工不支持断言率、缺证诚实率。

## 关闭条件

每个公布数字必须能追溯到源码版本、输入摘要、预测文件和计算程序；材料不足时列出缺料项并保持 `not_run`。`completed`、`validation=passed` 或引用存在不等于 Agent 有增益，也不等于真实操作者/攻击成功。
