# 规则边界

规则配置只描述可复核的观测条件，不能把样例标签写成命中条件。

- `R01`–`R06` 与 `freeze.json` 保持历史语义；更新必须另建版本、依据和回归。
- `R12`–`R30` 的包级/协议规则各有独立 freeze 文件，历史 finding 用保存的配置复现。
- `R31`（纯失败认证猜测）是 2026-11-26 新增的独立规则，不修改 R02 的“失败后成功”语义，也不把失败次数解释为字典使用或登录成功。配置与摘要见 `R31.json`、`auth-guess-freeze.json`。
- 规则命中只说明观测符合判据；授权范围、正常业务、成功执行、家族归属和真实操作者仍需分别举证。
- 新增规则进入运行时前必须冻结配置、覆盖正例/正常对照/反例，并通过 `python -m pytest` 相关契约测试。
